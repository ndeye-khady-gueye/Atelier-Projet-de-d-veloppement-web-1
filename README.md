# Atelier-Projet-de-d-veloppement-web-1
# NRV.net – Billetterie du Festival Nancy Rock Vibration

Application web de billetterie en ligne pour le festival **Nancy Rock Vibration** (NRV), réalisée dans le cadre de la SAE "Atelier-Projet de développement web 1" (BUT 3 Informatique DWM, IUT Nancy-Charlemagne).

---

## 🛠️ Architecture Technique

* **Backend :** API RESTful en **PHP 8.3 / Slim 4** (Architecture Hexagonale, PDO, PHP-DI)
* **Frontend :** Single Page Application (SPA) en **HTML5 / SCSS / JS Vanilla** (Requêtes `fetch`, templates **Handlebars**)
* **Base de données :** **PostgreSQL 16**
* **Conteneurisation & Orchestration :** **Docker** & **Docker Compose**

---
